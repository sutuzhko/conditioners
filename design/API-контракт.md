# API-контракт — ТулаКлимат

Контракт между фронтендом (сайт `Кондиционеры Тула.dc.html`, `База знаний.dc.html`) и админкой (`Админ-панель.dc.html`) с одной стороны и бэкендом с другой. Сейчас фронт работает на мок-хранилище (`data.js` + localStorage, ключ `tk-data-v1`) — структуры данных ниже совпадают с ним один в один: чтобы перевести фронт на сервер, достаточно заменить `loadData()/saveData()` на эти запросы.

Базовый URL: `https://api.tulaklimat.ru` (пример). Все ответы — `application/json; charset=utf-8`.

---

## 1. Авторизация (админка)

| Метод | Путь | Описание |
|---|---|---|
| POST | `/api/auth/login` | Вход. Тело: `{ "login": "...", "password": "..." }` → `200 { "token": "<JWT>" }`, `401` при ошибке |
| POST | `/api/auth/logout` | Инвалидация токена (опционально) |

Все `POST/PUT/PATCH/DELETE` из админки — с заголовком `Authorization: Bearer <JWT>`.
Публичные `GET` для сайта — без авторизации.

---

## 2. Публичные данные для сайта

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/public/site` | Всё для рендера сайта одним запросом (см. ниже) |
| GET | `/api/public/articles` | Список опубликованных статей (без `body`) |
| GET | `/api/public/articles/{slug}` | Одна статья целиком |

`GET /api/public/site` → `200`:

```json
{
  "models":   [ /* только visible=true, см. §3 */ ],
  "prices":   [ /* §4 */ ],
  "extras":   { /* §4 */ },
  "contacts": { /* §5 */ },
  "legal":    { /* §6 */ },
  "reviews":  [ /* только status="approved", без служебных полей */ ],
  "articles": [ /* published=true, без body: slug, title, category, date, minutes, excerpt, cover */ ]
}
```

**SEO-требование:** сайт должен отдаваться сервером уже с данными (SSR или пререндер), а не собираться на клиенте — иначе поисковики не проиндексируют каталог, цены и статьи. `title`, `meta description/keywords`, JSON-LD (`HVACBusiness`, `FAQPage`, `Article`) уже размечены во фронте — при SSR подставлять актуальные значения из БД.

## 3. Модели (CRUD, админка)

Объект `Model`:

```json
{
  "id": "m09",
  "badge": "09",
  "name": "Сплит-система 09",
  "areaMax": 27,
  "tag": "инвертор",
  "priceNum": 38500,
  "photo": "https://cdn.../models/m09.jpg",
  "link": "https://постащик.../tovar",
  "visible": true,
  "specs": [
    { "k": "Площадь", "v": "до 27 м²" },
    { "k": "Уровень шума", "v": "21 дБ" }
  ]
}
```

- `specs` — произвольный упорядоченный список пар «название → значение». Таблица сравнения на сайте строится как объединение ключей `k` всех видимых моделей; отсутствующее значение выводится прочерком. Никакого фиксированного набора характеристик на бэкенде быть не должно.
- `link` — необязательная внешняя ссылка на страницу товара.
- `photo` — URL; пустая строка = нет фото.

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/models` | Все модели (включая скрытые) |
| POST | `/api/models` | Создать. Тело — `Model` без `id` → `201` с `id` |
| PUT | `/api/models/{id}` | Обновить целиком |
| PATCH | `/api/models/{id}` | Частично (например `{ "visible": false }`) |
| DELETE | `/api/models/{id}` | Удалить |
| POST | `/api/models/{id}/photo` | Загрузка фото: `multipart/form-data`, поле `photo` (jpeg/png/webp, ≤ 5 МБ). Сервер сжимает до ~1200px по большей стороне → `200 { "photo": "<url>" }` |

## 4. Цены и доп-услуги

```json
{
  "prices": [
    { "cls": "07", "power": "2.0 кВт", "area": "до 20 м²", "price": 5500, "term": "3–4 часа" },
    { "cls": "09", "power": "2.6 кВт", "area": "до 27 м²", "price": 6000, "term": "3–4 часа" },
    { "cls": "12", "power": "3.5 кВт", "area": "до 35 м²", "price": 6500, "term": "4 часа" },
    { "cls": "18", "power": "5.3 кВт", "area": "до 50 м²", "price": 8000, "term": "4–5 часов" }
  ],
  "extras": { "trassaPerM": 700, "shtrobPerM": 800, "heightWorks": 2000 }
}
```

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/prices` | Текущие цены и ставки |
| PUT | `/api/prices` | Обновить весь блок (тело как выше) |

Калькулятор на сайте считает: `база(cls) + max(0, трасса−3м)×trassaPerM + (этаж 10+ ? heightWorks : 0) + (штробление ? трасса×shtrobPerM : 0)`, всё × количество.

## 7. База знаний (статьи)

Объект `Article`:

```json
{
  "id": "a1",
  "slug": "kak-vybrat-kondicioner",
  "title": "Как выбрать кондиционер для квартиры",
  "category": "Выбор",
  "date": "2026-05-12",
  "minutes": 6,
  "cover": "https://cdn.../covers/a1.jpg",
  "excerpt": "Короткий анонс для списка и главной.",
  "body": "Текст с разметкой…",
  "published": true
}
```

- `body` — плоский текст с лёгкой разметкой, которую рендерит фронт: `## заголовок`, `### подзаголовок`, `- пункт списка`, `> врезка`, `**жирный**`. Блоки разделяются пустой строкой.
- `slug` — уникальный, латиница/дефисы; генерируется из заголовка, если не задан.

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/articles` | Все статьи (админка) |
| POST | `/api/articles` | Создать → `201` |
| PUT | `/api/articles/{id}` | Обновить |
| PATCH | `/api/articles/{id}` | Например `{ "published": false }` |
| DELETE | `/api/articles/{id}` | Удалить |
| POST | `/api/articles/{id}/cover` | Обложка: `multipart/form-data`, поле `cover` → `200 { "cover": "<url>" }` |

## 8. Отзывы

Объект `Review`:

```json
{
  "id": "r5",
  "name": "Игорь П.",
  "district": "Привокзальный р-н",
  "rating": 5,
  "text": "Текст отзыва — НЕ редактируется никогда",
  "photo": "https://cdn.../reviews/r5.jpg",
  "date": "2026-07-04",
  "status": "pending"
}
```

`status`: `pending` (на модерации) → `approved` (опубликован) | `rejected` (невалидный/снят с публикации) | `archived` (архив: позвонить клиенту и уточнить, что улучшить). Текст отзыва неизменяем — модератор меняет только статус.

| Метод | Путь | Описание |
|---|---|---|
| POST | `/api/reviews` | **Публичный.** Приём отзыва с сайта. `multipart/form-data`: `name` (string, обяз.), `district` (string), `rating` (int 1–5, обяз.), `text` (string ≥ 10 символов, обяз.), `photo` (file, необяз., ≤ 5 МБ). Создаётся со `status="pending"` → `201 { "id": "..." }`. Защита: rate-limit по IP + honeypot-поле |
| GET | `/api/reviews?status=pending` | Админка: список по статусу (без параметра — все) |
| PATCH | `/api/reviews/{id}/status` | Смена статуса: `{ "status": "approved" \| "rejected" \| "archived" }` |
| DELETE | `/api/reviews/{id}` | Удалить безвозвратно |

## 9. Заявки с сайта

| Метод | Путь | Описание |
|---|---|---|
| POST | `/api/leads` | **Публичный.** `multipart/form-data`: `name`*, `phone`*, `topic` (Монтаж и установка / Сервис и ремонт / ТО и чистка / Консультация), `place`, `qty`, `time`, `address`, `comment`, `photo` (file, необяз. — фото места установки) → `201` |
| POST | `/api/leads/to-reminder` | Напоминание о ТО: `{ "phone": "...", "when": "..." }` → `201` |

Сейчас сайт шлёт заявки напрямую в Telegram Bot API из браузера (токен в Tweaks). **Для боевого сайта отправку обязательно перенести на бэкенд** — токен бота не должен светиться в клиентском коде.

## 10. Уведомления в Telegram

Бэкенд шлёт владельцу сообщение при каждом событии (`sendMessage` / `sendPhoto`, если приложено фото).

**Новый отзыв — с кнопками модерации** (`inline_keyboard`, `callback_data` вида `rev:<action>:<id>`):

```json
{
  "chat_id": "<ADMIN_CHAT_ID>",
  "text": "⭐ Новый отзыв на модерации\n\n👤 Игорь П. · Привокзальный р-н\n★ Оценка: 5/5\n💬 Вчера установили 09-ку…\n\nID: r5",
  "reply_markup": {
    "inline_keyboard": [[
      { "text": "✅ Одобрить", "callback_data": "rev:approve:r5" },
      { "text": "🚫 Запретить", "callback_data": "rev:reject:r5" },
      { "text": "📦 Архив", "callback_data": "rev:archive:r5" }
    ]]
  }
}
```

Обработчик `callback_query` вызывает тот же `PATCH /api/reviews/{id}/status` и редактирует сообщение (`editMessageText`), дописывая итог: «✅ Опубликован». Так модерация работает и из админки, и из Telegram, оставаясь консистентной.

**Новая заявка** — текст в формате, который уже шлёт фронт (тема, имя, телефон, адрес, тип помещения, кол-во, время звонка, комментарий; фото места установки — через `sendPhoto` с этим текстом в `caption`).

## 11. Ошибки

```json
{ "error": { "code": "validation_error", "message": "Поле rating обязательно (1–5)", "field": "rating" } }
```

`400` — валидация, `401` — нет/просрочен токен, `404` — нет объекта, `429` — rate-limit (публичные POST), `500` — прочее.
