# Черновики

Промежуточные доски, из которых выросли рабочие. В `canvas.json` их нет, и
реализовывать по ним нельзя — числа и подписи в них устарели.

| Черновик | Куда переехал |
| --- | --- |
| `Kit2`, `Kit3` | `Kit` |
| `TokensPal` | `Tokens` |
| `Tabs`, `Tabs2` | `OrderTabs`, `OrdersTabs`, `CardTabs` |
| `OrderTabs2`, `OrderTabs3` | `OrderTabs` |
| `OrdersTabs2` | `OrdersTabs` |

Лежат здесь, а не удалены: в `OrderTabs2` разобрана себестоимость материалов,
которую CRM §11.7 отложил вместе с §8.2. Когда владелец её примет — брать
оттуда, а не рисовать заново.
