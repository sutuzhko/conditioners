# BUGS.md

> Журнал замечаний и незакрытых задач. Заведён, чтобы найденное не терялось в переписке — контекст сессии не переживает сессию.

Статусы: `🔴` открыт · `🟡` в работе · `✅` закрыт
Приоритеты: `P1` ломает заявки, оплату или индексацию · `P2` заметно мешает · `P3` косметика

## Открытые — вёрстка на всех ширинах

### 🔴 P1 · Ритм отступов между блоками всё ещё рваный

Правило «отступ только сверху» (ADR-037) приведено к единому виду в файлах
блоков, но на странице разница между секциями по-прежнему видна. Причины,
которые нужно проверить по очереди:

1. Секции с собственным фоном (`--bg-soft`, `--lead-grad`) держат отступ и
   снизу — это осознанно, но рядом с соседом на общем фоне суммарный зазор
   получается двойным.
2. Внутри блоков заголовок и содержимое добавляют свои `margin`, и они не
   выровнены между блоками.

Мерить по факту в браузере (`getBoundingClientRect`), а не по CSS: значения
`clamp` на разных ширинах дают разный результат.

### 🔴 P2 · Сетка с остатком оставляет висящий ряд

Общая болезнь всех сеточных блоков, а не одного: карточки разложены жёсткой
сеткой, и при числе элементов, не кратном числу колонок, последний ряд стоит
полупустым. Видно в тизере Базы знаний (4 статьи на 3 колонки — четвёртая
одна) и в каталоге (4 модели на 3 колонки). Количество моделей и статей
задаётся в админке, поэтому подобрать «удобное» число нельзя.

Лечится общим правилом, а не по блокам: раскладка не должна зависеть от
остатка от деления. Файлы: `widgets/knowledge/KnowledgeTeaser.module.css`,
`widgets/catalog/Catalog.module.css`.

### 🔴 P2 · Полоса доверия переносит содержимое на вторую строку

На средней ширине четыре пункта не помещаются в ряд и четвёртый уезжает
вниз, ломая высоту первого экрана. Нужна не перестройка в столбец, а
горизонтальная прокрутка ряда — с автопрокруткой, останавливающейся при
наведении и при `prefers-reduced-motion`. Файл:
`widgets/trust/TrustStrip.module.css`.

### 🔴 P2 · Ряд симптомов переносится вместо прокрутки

Шесть кнопок симптомов уже на широком экране занимают две строки, а на
телефоне встанут в четыре — блок диагностики разъезжается по высоте, и
выбранный симптом уезжает от результата. Нужна та же горизонтальная лента с
прокруткой, что и для полосы доверия. Файл:
`widgets/service/Diagnostics.module.css`.

### 🔴 P2 · Калькулятор монтажа горизонтальный, нужен в две колонки

Сейчас поля идут в ряд, смета — снизу. Нужна раскладка «корзины»: слева
параметры, справа смета с итогом и кнопкой. Причина не в красоте: при
добавлении строк в смету блок сейчас прыгает по высоте.

### 🔴 P2 · Погоды в Туле нет в первом экране

В макете рядом с заголовком чип с текущей и пиковой температурой. При
переносе блок сознательно выброшен: это внешний запрос к open-meteo на
критическом пути LCP (PIXEL_SPEC, отступление №7). Заказчик хочет его
вернуть — значит нужен вариант без ущерба первому экрану: серверный запрос
с кэшем на час и деградацией без падения страницы, а не запрос из браузера
при загрузке.

### 🔴 P3 · Мелкие расхождения блока экономии с макетом

Кнопки режима крупнее макетных (кит `Button sm`: 40px, радиус 9px), у
активной есть тень, которой в макете нет. Бегунки ползунков толще: кит
рисует их вручную вместо `accent-color`. Подписи ползунков блок стилизует из
своего модуля — лазейка мимо кита, просится проп размера у `RangeSlider`.

### 🔴 P3 · Ступени отступа карточки закрывают макет с погрешностью

В макете 26 / 30 / 32 / 34px, в ките `lg` = 28 и `xl` = 32. Расхождение до
2px. Дробить шкалу дальше — превратить её в набор произвольных чисел;
решение отложено сознательно (ADR-039).

### 🔴 P3 · Подпись в замке логотипа: два источника противоречат

Прототип главной даёт 10.5px / 0.05em, файл логотипов — 11px / 0.06em.
Нужен арбитраж.

## Открытые — инфраструктура

### 🔴 P1 · Нет браузеров для Playwright в образе

Снимки визуальной регрессии (ADR-021) запустить негде: Alpine официально
Playwright не поддерживает. Нужен системный Chromium в дев-стадии либо
отдельный образ. Без этого пиксель-перфект держится ровно до следующего
коммита.

### 🔴 P2 · Порядок CSS-модулей в продовой сборке не проверен

Дефект с бургером на десктопе зависел от порядка файлов в бандле (ADR-038),
а он может отличаться между дев-сборкой и продом. Проверено только в деве.

### 🟡 P2 · Запуск проекта без Docker не работает

`pnpm install` на хосте отдаёт пустой `node_modules` и 2481 ошибку типов —
клиент Prisma не сгенерирован. Нужен рабочий путь мимо Docker: он был
обещан, чтобы среда Claude не поднимала контейнеры.

### 🔴 P3 · Две проверки готовности настроек

`entities/settings/lib/findSettingGaps` и `checkReadiness` +
`REQUIRED_FIELDS` в репозитории. Смысл разный, но кандидат на сведение.

## Закрытые

### ✅ P1 · Страницы кластера повторяют блоки главной

Закрыто удалением кластера: сайт стал лендингом (ADR-049, решение
заказчика). `/catalog`, `/prices`, `/installation`, `/service`, `/reviews`,
`/contacts` удалены вместе с тестами и контентом; таблица сравнения моделей
осталась в виджете каталога на главной.

### ✅ P1 · Битые ссылки после перехода на английские адреса

Адреса собраны в `shared/seo/routes.ts` одной картой, копия в
`server/revalidate.ts` удалена. Ревалидация из админки сбрасывает
существующие маршруты, а не русские адреса, которых нет.

### ✅ P1 · Навигация ведёт только на якоря главной

После ADR-049 якоря главной — и есть верный адрес раздела. Навигация
записана в форме `/#якорь`, поэтому работает и со страниц статей.

### ✅ P2 · Транслитерация в якорях и параметрах запроса

`#zayavka`, `#ceny`, `#etapy`, `#diagnostika`, `#otzyvy`, `#kontakty`,
`?rubrika=` заменены на английские (`#lead`, `#prices`, `#installation`,
`#service`, `#reviews`, `#contacts`, `?category=`). Требование заказчика:
транслита в адресах сайта быть не должно нигде.

### ✅ P1 · Двадцать тестов блока экономии удалены молча

При сведении блока с макетом агент удалил 20 тестов из 22, оставив
осиротевшие помощники. Общее число тестов в проекте при этом росло за счёт
других агентов, и падение осталось незаметным. Восстановлено из истории и
адаптировано под текущую реализацию. **Урок: число тестов по проекту не
показатель — покрытие нужно смотреть по файлу.**

### ✅ P1 · Кольцо фокуса не видно на тёмном фоне

Токен был заливкой с прозрачностью 12%. Заменён на двухслойное кольцо; для
контейнеров с `overflow: hidden` — врезанный вариант. Прошло по всему киту,
а не по трём компонентам, как было сначала.

### ✅ P2 · Бургер-меню показывалось на десктопе

Одинаковая специфичность у класса шапки и класса кита; побеждал файл,
подключённый позже (ADR-038).

### ✅ P2 · Телефон-заглушка занимал четверть шапки

В макете телефона в шапке нет; оставлен там, где навигация уезжает в меню.

### ✅ P2 · Ступенька фона над шапкой

Первый экран уведён под шапку отрицательным отступом.

### ✅ P2 · Первый экран не давал увидеть полосу доверия

874 → 792px: полоса видна на 68px без прокрутки при экране 860.

### ✅ P2 · Форма заявки растягивалась во всю ширину

Секция была без контейнера; заменена на двухколоночную из макета.

### ✅ P2 · Вертикальный ритм секций вдвое разрежённее макета

Разбор спецификации терял третье значение отступа (ADR-037).

### ✅ P2 · У последней секции не было отступа снизу

Задано структурно: `main > :last-child`.

### ✅ P3 · Блок «как обманывают» дублировал разбор сметы

Убран с главной; после ADR-049 удалён совсем вместе со страницей установки —

### ✅ P3 · Плашка «характеристики из админки»
