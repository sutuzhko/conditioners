# BUGS.md

> Журнал багов проекта. Заводится сразу, чтобы найденное не терялось в переписке.

## Как читать

Статусы: `🔴` открыт · `🟡` в работе · `✅` закрыт
Приоритеты: `P1` ломает заявки, оплату или индексацию · `P2` заметно мешает · `P3` косметика

Шаблон:

```
## BUG-NNN — короткое имя   [статус · приоритет]

**Где:** файл или страница
**Как воспроизвести:** шаги
**Ожидалось:** …
**Получилось:** …
**Причина:** заполняется при разборе
**Исправление:** ссылка на коммит
```
