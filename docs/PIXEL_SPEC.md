## 🔴 Разрешённые отступления — их НЕ откатывать

Эти расхождения с макетом приняты сознательно и зафиксированы решениями. Агент, который «починит» их обратно, сломает проект.

| Отступление                                                       | Причина                                                                                                                                                                                                                    |
| ----------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Onest вместо Space Grotesk, JetBrains Mono вместо Space Mono**  | у шрифтов макета нет кириллицы; в самом макете русские заголовки рисовались системным шрифтом (ADR-025)                                                                                                                    |
| **Тёмные оттенки ошибки, предупреждения и фона выбранного чипа**  | оттенки макета не проходят AA по контрасту (DESIGN_BRIEF §12)                                                                                                                                                              |
| **Градиент в H1 сужен по темам**                                  | крайняя точка `#22D3EE` на белом даёт 1.9:1                                                                                                                                                                                |
| **Логотип 1a «Поток»**                                            | знак в шапке макета отменён заказчиком (ADR-022)                                                                                                                                                                           |
| **Вся мобильная раскладка**                                       | медиа-запросов в макете нет вообще — раскладка ниже 1200px наша (DESIGN_BRIEF §6)                                                                                                                                          |
| **Убранные цифры-факты**                                          | «1200 установок», «3 000 ₽», «гарантия 3 года», «от 1 500 ₽» — данные компании, инвариант 8                                                                                                                                |
| **Нет погодного чипа, частицы урезаны**                           | внешний запрос и анимация на критическом пути LCP                                                                                                                                                                          |
| **Нет фотослотов**                                                | реальных фотографий пока нет                                                                                                                                                                                               |
| **Анимация появления секций**                                     | в реализации на CSS блок навсегда оставался прозрачным на узком экране                                                                                                                                                     |
| **Первый экран уходит под шапку**                                 | шапка прозрачная и sticky, её фоном оставался основной цвет — над ней была видна ступенька. Внутрь hero шапку перенести нельзя: `position: sticky` ограничен родителем, а `overflow: hidden` у секции отключает его совсем |
| **Кольцо фокуса двухслойное, у обрезающих контейнеров врезанное** | прежний токен был заливкой с прозрачностью 12% и на тёмном фоне не читался; `overflow: hidden` у аккордеона и области прокрутки обрезает внешнее кольцо                                                                    |
| **Секция формы заявки в контейнере 720px**                        | без контейнера карточка расползалась во всю ширину экрана                                                                                                                                                                  |
| **Блок «Экономия инвертора» сверке не подлежит**                  | заказчик планирует его переработку — трогать не нужно                                                                                                                                                                      |

## Как сверять

1. Открой свой блок в Storybook на **1200px** — это ширина, для которой макет и рисовался. Сверь по таблице: фон секции, вертикальный ритм, размер заголовка, радиусы, размеры шрифта.
2. Переключи **тёмную тему** и сверь снова. Тёмные значения токенов уже описаны в `tokens.css` — расхождения обычно не в значениях, а в том, какой токен взят для поверхности.
3. Проверь **320 / 375 / 768** — здесь макета нет, сверять не с чем; смотри, что ничего не разъехалось и страница не скроллится по горизонтали.
4. Открой соответствующую секцию прототипа в браузере рядом, если сомневаешься: `design/Кондиционеры Тула.dc.html` — обычный HTML-файл.

Расхождение, которое ты считаешь осознанным улучшением, **не исправляй молча**: опиши его в отчёте, и оно либо попадёт в таблицу отступлений, либо будет откачено.
