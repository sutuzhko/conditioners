## Как сверять

1. Открой свой блок в Storybook на **1200px** — это ширина, для которой макет и рисовался. Сверь по таблице: фон секции, вертикальный ритм, размер заголовка, радиусы, размеры шрифта.
2. Переключи **тёмную тему** и сверь снова. Тёмные значения токенов уже описаны в `tokens.css` — расхождения обычно не в значениях, а в том, какой токен взят для поверхности.
3. Проверь **320 / 375 / 768** — здесь макета нет, сверять не с чем; смотри, что ничего не разъехалось и страница не скроллится по горизонтали.
4. Открой соответствующую секцию прототипа в браузере рядом, если сомневаешься: `design/Кондиционеры Тула.dc.html` — обычный HTML-файл.

Расхождение, которое ты считаешь осознанным улучшением, **не исправляй молча**: опиши его в отчёте, и оно либо попадёт в таблицу отступлений, либо будет откачено.
