**PRD:** [docs/prd-admin-panel-mockup-conformance.md](prd-admin-panel-mockup-conformance.md)
**Макет:** [холст «Панель ТулаКлимат»](https://claude.ai/code/artifact/6283f576-0c4a-4581-99e2-a0da228858e2) · исходники `design/admin/`
**Основание:** [ADR-307](DECISIONS.md)
**Дата:** 2026-09-04

## Откуда взяты числа

Сверка сделана 4 сентября: тринадцать разделов сняты с живого стенда на 1440, 768
и 390 и положены рядом с артбордами макета, отрендеренными из `design/admin/`.
Оценка соответствия грубая и обоснована числом блоков: «блок есть и совпадает» — 1,
«есть, но иначе» — 0,5, «нет вовсе» — 0.

| Заказы          | 30 % | 25 %            | 25 %            |
| Карточка заказа | 25 % | не сверялась    | **10 %**        |
| Заявки          | 32 % | 30 %            | 30 %            |
| Клиенты         | 27 % | макет не рисует | макет не рисует |

Замеры-основания той же смены: `pnpm check` зелёный (334 файла, 3715 тестов),
`admin-density.mjs` зелёный (526 целей на 768, ни одной мельче 44×44; вбок не едет
ни один раздел), `admin-contrast.mjs` — 2 нарушения в календаре.

## Общий словарь

Пороги проекта: **600 / 900 / 1200**, нижняя граница 320. Кадры макета сняты на
**1440 / 768 / 390** — это середины диапазонов, а не сами пороги.

## Порядок

Фазы 1–4 обязаны идти по порядку: они кладут то, чем собираются все экраны.
Фазы 5–10 независимы между собой и берутся в любом порядке. Фаза 11 — последняя.

### Фаза 1: Оболочка приходит к макету

**Цель:** Tracer Bullet. Владелец получает макетную оболочку во всех тринадцати
разделах разом; содержимое пока прежнее. После неё любую фазу можно начинать.
**Затрагивает:** frontend

**Задачи:**

- [ ] Убрать верхнюю полосу: `NavToggle` уходит влево от заголовка раздела,
      переключатель темы — в строку значков справа, «Открыть сайт» — вниз колонки
      к «Настройкам» и «Профилю». Радиус мал: `AdminShell` зовут четыре файла, ни
      один сквозной сценарий на текст полосы не опирается
- [ ] Карточка вошедшего: инициалы, имя, роль и меню — вместо логина без меню
- [ ] Счётчики у пунктов навигации: новые обращения, отзывы на модерации,
      активные наряды. Числа считаются на сервере, приходят в оболочку пропсами
- [ ] Рельс навигации опускается с 900 до 600 (ADR фазы): на 768 панель работает
      планшетом, а не большим телефоном. Цели рельса ниже 900 — 44px (ADR-183);
      подсказка значка — `Tooltip` кита вместо `title=`
- [ ] Тесты: сквозной сценарий обходит тринадцать разделов на 390, 768 и 1440 —
      `h1` на каждой странице, активный пункт подсвечен, вбок не едет; снимки
      88 историй `Админка/` пересняты, расхождения приняты ярлыком

**Когда готова:** оболочка совпадает с макетом на трёх ширинах; счётчики живые;
на 768 стоит рельс; `admin-density.mjs` зелёный.

### Фаза 2: Действия живут в строке

**Цель:** закрыть счёт владельца «нельзя удалить и переименовать». Действие,
существующее в карточке, становится достижимым из списка.
**Затрагивает:** frontend

**Задачи:**

- [ ] Подключить `RowMenu` (собран, позван нулём экранов) к спискам, где действие
      спрятано в карточку: склад, каталог, База знаний
- [ ] Подключить `TableActions` (собран, зовёт только `OrderTable`) к остальным
      таблицам панели — круглые действия строки по макету
- [ ] Свести набор действий строки к одному правилу: открыть · править · убрать,
      удаление красное, необратимое спрашивает подтверждение. Образец в проекте
      уже есть — отзывы, зоны хранения, прайс, телефоны компании
- [ ] Архив вместо удаления там, где удаление уносит журнал (ADR-134, склад) —

      открывая карточку; проверка, что отказ от подтверждения ничего не меняет

**Когда готова:** в каждом списке панели действия достижимы из строки; ни один
список не требует «догадаться открыть карточку».

## Что решается отдельно, а не этим планом

| Вопрос                             | Почему не здесь                                                                                                                                                                                         |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 🔴 **Причина отказа наряда**       | Поля нет в схеме `Order` (есть только `deductionReason` про удержание). Без него вкладка «Отказы» бессмысленна по подписи самого артборда. Ответ владельца: мигрируем или строка в PIXEL_SPEC           |
| 🔴 **Маржа**                       | Ни в схеме, ни в коде; CRM §11.7 фиксирует её отсутствие решением. Макет показывает её в четырёх местах                                                                                                 |
| 🔴 **Загрузка монтажника в часах** | Учёта нет вовсе. Плитка «Средняя загрузка 36 ч из 40» и колонка «Загрузка недели» нереализуемы                                                                                                          |
| **Колокол со счётчиком**           | В схеме нет понятия «прочитано»: `Notification` — исходящая очередь доставки. Либо колокол показывает те же счётчики, что навигация (тогда он часть Фазы 1), либо это центр уведомлений и отдельный PRD |
| **Глобальный поиск в шапке**       | Поиск по клиенту, адресу и заметке описан в CRM §3.5.1 и API §9 для календаря. Распространение на всю панель — своя задача с ADR                                                                        |
| **Переименование группы склада**   | Группа — свободная строка, список складывается из позиций намеренно (`schema.prisma:488`). Переименовать сразу во всех позициях нельзя. Это продуктовый вопрос, а не дефект                             |
| **Рамка переработки в календаре**  | 1,49:1 и 2,14:1 при норме 3:1, но состояние дублируется словом. Либо именное допущение с причиной, либо правка токена во всей панели                                                                    |
| **Маска затухания таблицы**        | Открытый #434: принята против неподтверждённого диагноза, мешает мерить контраст (16 узлов «не измерено»)                                                                                               |
