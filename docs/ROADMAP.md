## Риски

| Риск | Что делаем |
|---|---|
| Сезонность: запустились в мае — сезон потерян | Выкладка зимой, до начала спроса |
| `api.telegram.org` недоступен с VPS | Email как основной канал, транспорт Telegram переключаемый |
| Нет реального каталога и фото | Карточки товаров без содержания не дадут трафика — блокер Этапа 4, поднимать заранее |
| Нет настоящих отзывов | Стартуем с пустым разделом и формой. Выдуманные — запрещены |
| Прототип неадаптивен | Адаптив заложен в UI Kit с Этапа 2, а не доводится в конце |
| Плейсхолдеры уехали в прод | Заглушки заведомо заметные («ЗАПОЛНИТЕ В АДМИНКЕ»), индикатор готовности в админке, чек-лист выкладки |
| Истёкшая скидка висит на статической странице | Ревалидация карточек товара не реже раза в сутки |
| Среда разработки разошлась с боевой | Дев только в Docker, версии Node и Postgres общие с продом (ADR-017) |
