## ТЕКУЩАЯ ПОЗИЦИЯ

Публичная часть сайта собрана: главная из пятнадцати блоков, кластер страниц,
база знаний, политика. 106 файлов тестов, 832 теста зелёные. Разработка идёт
в Docker (`docker-compose.dev.yml`), сайт открывается на `localhost:3000`.

Готовы Этапы 1–5. **Не начаты Этапы 6–9: админки нет вообще**, а без неё
сайт нельзя отдать владельцу — все данные о компании и каталог сейчас
лежат в сидах БД и правятся только руками.

Ближайший шаг — Этап 6: админка. Параллельно с ним — долг по вёрстке из
[BUGS.md](BUGS.md): там 30 записей, из них открытых с приоритетом P1
несколько, и они видны посетителю.

**Чего ещё нет, хотя блоки написаны:** JSON-LD собран в `shared/seo`, но
ни на одной странице не вызывается; снимков Playwright нет (браузеры не
ставятся в Alpine); запуск вне Docker не работает.

**Запуск планируется до сезона.** Индексация нового домена занимает 3–6 месяцев, продажи идут с мая по август — значит выкладываться нужно зимой, а не в мае.
