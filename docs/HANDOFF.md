```

```

## Что знать до первой правки

- **🔴 Никакой транслитерации в адресах.** Ни в маршрутах, ни в якорях, ни в
  параметрах запроса: `#lead`, а не `#zayavka`; `?category=`, а не
  `?rubrika=` (ADR-042, ADR-049). Русскими остаются только слаги статей,
  которые задаёт владелец.
- Навигация ведёт на `/#якорь`, а не `#якорь`: те же ссылки стоят в шапке
  страниц статей, где голый якорь вёл бы в никуда.
- **Git — только у оркестратора** (ADR-044). Агенты к нему не подходят:
  индекс общий, и параллельные коммиты сметают чужие файлы.
- **Не больше четырёх агентов сразу** (ADR-045) — машина не вытягивает.
- Коммит: `git commit -- <пути>`, а не `git add` со всем индексом (ADR-032).
  Пути со скобками — в кавычках, иначе zsh их проглотит и коммит станет пустым.
- История не переписывается (ADR-033). `--amend` чужого коммита запрещён.
- Упоминаний Claude в коммитах быть не должно, включая соавторство.
- CSS Modules изолируют имена, но не каскад: при равной специфичности
  выигрывает порядок сборки (ADR-038). Отсюда удвоенные классы в коде.
- Отступления от макета перечислены в [PIXEL_SPEC.md](PIXEL_SPEC.md).
  Они осознанные — «чинить» их обратно не нужно.
- Удалили страницу — почистите `.next/types/app/(site)/<имя>`: `tsc` иначе
  ругается на несуществующий модуль из старого сгенерированного типа.

## Чего нет и почему

| Чего нет                      | Почему                                                                          |
| ----------------------------- | ------------------------------------------------------------------------------- |
| Снимков Playwright            | Браузеры не ставятся в Alpine; раннер настроен                                  |
| Запуска вне Docker            | `pnpm install` на хосте отдаёт пустой `node_modules`                            |
| Погоды в Туле в первом экране | Блок из макета не сделан; нужен серверный запрос с кешем на час, не из браузера |
| Карты на контактах            | Решение о встраивании отложено                                                  |
| Блока «Напомним про чистку»   | Отложен до админки: без раздела заявок напоминания некому обрабатывать          |
| Отдельных посадочных страниц  | Сайт — лендинг по решению заказчика (ADR-049)                                   |
