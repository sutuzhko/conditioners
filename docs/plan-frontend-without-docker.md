# Plan: Запуск приложения без Docker — база в контейнере, Next на хосте

**PRD:** [prd-frontend-without-docker.md](prd-frontend-without-docker.md)
**Дата:** 2026-08-29

## Фазы реализации

### Фаза 1: Сайт открывается с хоста

**Цель:** Сквозной минимум — база в контейнере, приложение на хосте, главная
отдаётся с настоящими данными. Пока этого нет, остальные фазы проверять нечем.
**Затрагивает:** инфраструктура

**Задачи:**

- [ ] Завести способ поднять только Postgres, не поднимая `web`, `worker`,
      `caddy` и `storybook`
- [ ] Завести файл переменных для хоста: адрес базы через проброшенный порт,
      `UPLOADS_DIR` в существующий на хосте каталог, остальное — как в
      `.env.dev`
- [ ] Поставить зависимости и сгенерировать клиент Prisma под хост, не задев
      тома контейнера
- [ ] Проверка: `docker stats` показывает один контейнер и не больше 100 МБ;
      главная на хосте отдаёт те же цены и тот же каталог, что контейнерный
      запуск — сверено запросом к обеим

**Когда готова:** `pnpm dev` на хосте открывает сайт с данными из той же базы;
в Docker при этом работает только Postgres.

### Фаза 2: Панель работает целиком

**Цель:** Не только чтение: вход, правка и загрузка файла на хосте ведут себя
так же, как в контейнере.
**Затрагивает:** backend

**Задачи:**

- [ ] Проверить вход в панель на хосте и починить, если мешает схема `SITE_URL`
      или флаг `Secure` у cookie ([ADR-102](DECISIONS.md))
- [ ] Проверить правку цены: изменение видно на публичной странице
- [ ] Проверить загрузку изображения: файл сохраняется в каталог хоста и
      отдаётся обратно
- [ ] Проверка: сквозные сценарии `lead`, `price-update` и `company-legal`
      проходят против хостового запуска

**Когда готова:** Три обязательных сценария из [CLAUDE.md](CLAUDE.md) проходят
на хостовом запуске.

### Фаза 3: Проверки не требуют контейнера

**Цель:** Тесты, типы и хук коммита работают, когда контейнер `web` выключен.
Без этого режим неприменим: коммит станет невозможен.
**Затрагивает:** инфраструктура

**Задачи:**

- [ ] Научить `scripts/test-related.sh` работать без контейнера: при
      выключенном `web` прогонять тесты на хосте, а не отказывать
- [ ] Прогнать `pnpm test` на хосте целиком и сверить с контейнерным прогоном;
      расхождения перечислить поимённо с причиной
- [ ] Прогнать `pnpm typecheck` на хосте и записать вывод по
      [ADR-147](DECISIONS.md): причина («типы маршрутов лежат в `.next` внутри
      тома») исчезла или осталась
- [ ] Проверка: `git commit` проходит хук при выключенном контейнере `web`, и
      падает на заведомо сломанном тесте

**Когда готова:** Коммит и полный прогон возможны без контейнера `web`;
расхождения с контейнером известны поимённо.

### Фаза 4: Возврат к полному составу ничего не ломает

**Цель:** Два режима сосуществуют: переключение туда и обратно не требует
переустановки зависимостей и не портит ни один из них.
**Затрагивает:** инфраструктура

**Задачи:**

- [ ] Проверить, что `node_modules` хоста и тома контейнера не мешают друг
      другу: нативные пакеты и клиент Prisma у каждого свои
      ([ADR-028](DECISIONS.md))
- [ ] Проверить, что каталог загрузок хоста и том контейнера не путаются
      местами
- [ ] Проверка: подряд — хостовый запуск, полный состав, снова хостовый; на
      каждом шаге сайт открывается и панель пускает, без установки зависимостей

**Когда готова:** Переключение между режимами в обе стороны проходит без
дополнительных действий.

### Фаза 5: Режим записан в документах

**Цель:** По документации можно поднять оба режима, и в журнале записано, чем
за второй заплачено.
**Затрагивает:** документация

**Задачи:**

- [ ] Описать оба режима в [DEPLOY.md](DEPLOY.md) §2: команды и когда какой
      нужен
- [ ] Принять ADR: что именно отменяется из [ADR-017](DECISIONS.md), чем
      платим за расхождение сред, что остаётся защитой (CI собирает боевой
      образ и гоняет тесты в контейнере)
- [ ] Записать замер в [BUGS.md](BUGS.md): занятая память и загрузка машины в
      обоих режимах, до и после
- [ ] Проверка: сторонний читатель по [DEPLOY.md](DEPLOY.md) поднимает хостовый
      режим с нуля, не заглядывая в код

**Когда готова:** Оба режима описаны, решение записано ADR, замер в журнале.
